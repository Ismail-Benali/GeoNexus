# GeoNexus 2026 - Global Geopolitical & Intelligence Platform

### Arabic (العربية)

**GeoNexus 2026** هي منصة جيوسياسية واستخباراتية شاملة ومتكاملة لتحليل الدول، القارات، التحالفات العسكرية، الاقتصاد، الشركات الكبرى، ومؤشرات المخاطر (غسيل الأموال، الاتجار بالبشر، الإرهاب، والتهديدات الأمنية) لكل دولة في العالم من الماضي وحتى عام 2026.

#### المميزات الأساسية:
1. **خريطة العالم التفاعلية**: مدعومة بـ OpenStreetMap مع علامات تفاعلية لكل دولة.
2. **التحديث التلقائي المستمر**: دمج بيانات حية عبر GDELT Project API و RSS للتحديث الفوري للأحداث دون تدخل بشري.
3. **الملفات الشاملة للدول**:
   - رؤساء الدول والقيادات العسكرية والأحزاب السياسية وميزانيات الجيوش.
   - التحالفات الاستراتيجية (الناتو، بريكس، شانغهاي، وغيرها).
   - الشركات الكبرى، الاستثمارات، ومؤشرات الضغط الاقتصادي.
   - مؤشرات غسيل الأموال، الاتجار بالبشر، والتهديدات الإرهابية.
   - التسلسل التاريخي للأحداث حتى عام 2026.
4. **محرك بحث متقدم**: بحث سريع وفوري (عبر اختصار `Ctrl+K`) عن أي دولة، رئيس، حزب، شركة، أو قائد عسكري.
5. **دعم ثنائي اللغة**: دعم كامل للغة العربية (مع اتجاه RTL) واللغة الإنجليزية.

### English

**GeoNexus 2026** is a comprehensive global geopolitical and intelligence platform analyzing nations, continents, military alliances, economies, top corporations, and risk indicators (money laundering, human trafficking, terrorism, and security threats) for every country up to 2026.

#### Key Features:
1. **Interactive Global Map**: Powered by OpenStreetMap with interactive markers for all countries.
2. **Automated Live Updates**: Integrated GDELT Project API and RSS feeds for real-time geopolitical updates without manual intervention.
3. **Comprehensive Country Profiles**:
   - Presidents, military leadership, political parties, and military budgets.
   - Strategic alliances (NATO, BRICS, SCO, etc.).
   - Top corporations, investments, and economic pressure points.
   - Money laundering, human trafficking, and security threat assessments.
   - Historical events and milestones up to 2026.
4. **Advanced Search Engine**: Instant search (`Ctrl+K`) across countries, leaders, parties, companies, and commanders.
5. **Bilingual Support**: Full support for Arabic (with RTL) and English.

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/geonexus.git

# Navigate to project directory
cd geonexus

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
